# Приложения доставки для кафе

Шаблон мобильного приложения доставки еды. Под каждое кафе собираем демо с их настоящим
меню, ценами и фото и отправляем владельцу ссылку: «смотрите, это уже ваше приложение».

## Посмотреть

- Все демо: https://sopla1997r.github.io/dostavka-app/
- «Суши Имбирь» (Ленск): https://sopla1997r.github.io/dostavka-app/imbir/

Лучше открывать с телефона. На компьютере слева показывается текст для владельца кафе,
а справа само приложение в рамке телефона.

## Что умеет приложение

- Меню с фото, поиском и категориями, сторис и баннеры с акциями
- Карточка блюда: размеры, добавки, вес
- Корзина: доставка или самовывоз, бесплатная доставка от суммы, промокоды, списание бонусов
- Оформление заказа и отслеживание статуса (в демо статусы ускорены)
- Бонусная карта с уровнями
- Помощник в чате: советует блюда, отвечает про доставку, оплату и часы работы

В демо заказ никуда не уходит. Для настоящего клиента нужно подключить отправку заказов
кафе в Telegram или WhatsApp.

## Как устроено

| Что | Где |
|---|---|
| Шаблон приложения (один файл: вёрстка + логика) | `app/index.html` |
| Конфиг клиента: бренд, цвета, меню, акции, ответы помощника | `clients/<имя>.json` |
| Фото блюд клиента (имя файла = id блюда) | `clients/<имя>/img/web/` |
| Сборка демо | `node tools/build.js <имя>` → `docs/<имя>/` |
| Просмотр у себя | `node tools/serve.js` → http://localhost:4173/<имя>/ |
| Скачать фото с Tilda-сайта клиента | `tools/fetch-imbir-photos.js` (пример) |
| Ужать фото | `tools/shrink.ps1 <папка>` |
| Инструкция и промпт для нового клиента | `app/ПРОМПТ.md` |
| Список магазинов для рассылки (в репозиторий не попадает) | `leads/shops.json` → `node tools/make-table.js` → `leads/Магазины.xlsx` |

У каждого магазина своя ссылка: `https://sopla1997r.github.io/dostavka-app/<имя>/`.
Общего списка демо на сайте нет, чтобы кафе не видели демо друг друга.

Код шаблона под клиента не меняем. Новое кафе — это новый JSON и папка с фото.
